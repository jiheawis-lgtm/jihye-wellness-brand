# 브랜딩 워크북 — 채운 답안 (노션 Class 1~9 정리본)

> 만든 날: 2026-07-24 · 출처: 노션 「Class 워크북 (브랜딩 클래스 전용)」 Class 1~9.
> 방식: 대전제 + 성경 + 브랜딩방(00~04 문서) 방향으로 **빈 클래스(4~9)를 채우고**, Class 2는 업그레이드 노트만 얹음(원본 보존).
> 노션에는 각 질문 아래 ✅ 초록 콜아웃으로 들어가 있음. 이 파일은 그 사본.

## Class 1. 브랜딩 (기존 — 지혜님 원답, 유지)
출발선. "재활운동하는 곳" → 이후 클래스에서 '중심 재건'으로 승격. 원답은 씨앗으로 보존.

## Class 2. 정체성 (업그레이드 노트 추가)
- 해결 문제: 목·어깨·허리 통증 → **확장: 무너진 '중심'** (증상이 아니라 원인)
- 누구: 한국 40/30대 통증 → **전환: 다 해봤는데 흩어진 여자 (글로벌·영어)**
- 키워드: #체력부족 → **#중심재건 #nervoussystem #안티프래질 #몸과마음**
- 한 줄 정의: "체력 저질 여성이 수술없이…" → **"다 해봤지만 흩어진 여자가, 몸의 중심을 세워 마음·삶의 중심까지 다시 세우도록"** (EN: *I help people rebuild their center — body, mind, soul.*)

## Class 3. Why (기존 — 지혜님 원답, 강함, 유지)
타이레놀 안 듣던 나 → 해외·과로를 진통제로 버티다 몸이 무너짐 → 삼촌부부에게 회복 배우며 중심 되세움. **중심을 잃었다 되찾는 여정 자체가 메시지.**

## Class 4. 포지셔닝
- **Step1 (고객 3):** 과거의 나(안전이라는 감각 필요) / 다 해본 여자(무너지는 '이유'를 못 들어서) / 신앙·마인드셋으로 버틴 여자(몸과 마음 잇는 언어 없어서).
- **Step2 (공통점):** 방법이 부족한 게 아니라 **증상만 쫓았지 '중심'을 세운 적이 없음.**
- **Step3 (경쟁 재편):** 같은 업종=필라·재활·마인드풀 / 대체재=물치·PT·요가·신경계 코치(taytrace)·신앙 피트니스(Revelation) / 직접시도=유튜브 홈트·소마틱 릴스·자기계발 / 포기=진통제·체념.
- **Step4 (왜 나):** 무너짐의 사슬 되감아 원인=중심으로 + 몸→마음→하나님 세계관(대전제+성경) + 정직한 안티프래질.
- **Step5 (한 문장):** 우리는 **"다 해봤는데도 계속 무너지는 여자"의, 증상이 아니라 몸의 중심부터 다시 세우는 것** 전문이다.

## Class 5. 타겟
- **분류:** 겉은 잘 기능하지만 조용히 무너지는 여자 (예전의 나).
- **당연한 고민:** 상황=다 해봤는데 계속 무너짐, 쉬어도 더 불안 / 감정="다 해봤는데 왜 나만" / 제약=의지력 이미 최대, 시간 없음 / 원함=완벽한 몸 아니라 '무너져도 다시 서는' 안정.
- **절박한 상황 (고객 언어):** "쉬는 게 더 불안해요" / "몸이 안 꺼져요" / "다 해봤는데 왜 계속 이럴까요"
- **한 문장:** 다 해봤는데도 흩어져 있고, 쉬려 해도 더 불안한 — 조용히 무너지는 여자.
- **접점/근거:** 예전의 나 = 정확히 그 사람. 신경계 조절 = 2026 해외 웰니스 최대 화두(검증됨). 이미 지불 중(taytrace $27, MWH 구독). 불만은 '효과 없음' → 더 나은 해법 여지.

## Class 6. 경쟁
- **대안:** 미학 마인드풀 운동(MWH) / 신앙 피트니스(Revelation) / 신경계 크리에이터 / 유튜브 혼자 / 명상앱·자기계발서 / **그냥 참고 버티기(가장 큰 경쟁자).**
- **한계 & 기회:** 미학=왜가 얕음 → 구조·대전제로 '왜'를 준다 / 신앙=몸 메커니즘 약함+회복된 권위자 톤 → 정직+몸의 구조 / 신경계=세계관 없음 → 대전제로 구조화 / 혼자=흩어짐 → 함께 걷는 초대.
- **말 vs 진짜:** "더 예쁜 몸/스트레스 줄이기" → 실제 "무너져도 다시 중심 잡는 안정." **실제 원하는 것(중심)에 답하는 게 내 자리.**

## Class 7. 차별화
- **POP(기본):** 해부학·운동 지식, 안전한 큐잉, 꾸준한 콘텐츠, 기본 신뢰.
- **POD(교집합):** 증상이 아니라 **'중심'을 세운다 + 정직한 안티프래질.** (반복 단어 = 중심 + 정직 + 몸→마음)
- **축:** 밀착 — 완벽한 구루가 아니라 함께 걷는 사람.
- **DO/DON'T:** DO=사슬 되감기·세계관·정직한 고군분투·초대 / DON'T=증상 하나 잡기·완벽한 몸 이미지·자극 훅·정답 주입.
- **한 문장:** "운동 지식은 기본이고, 증상이 아니라 '중심'을 세운다는 것이 다릅니다. 그래서 다 해봤지만 계속 무너지던 사람에게 선택받습니다."

## Class 8. 원칙 / 메시지
- **재료:** 상황(흩어진·불안한 여자) + 대안 한계(왜·몸·세계관 부재) + 해결(몸의 중심부터) + POD(중심·정직).
- **메시지 (final KR):** **"문제는 당신이 아니라, 중심이었어요. 몸의 중심부터 다시 세웁니다."**
- **메시지 (final EN):** **"It's not willpower — it's your center. Rebuild it, starting with the body."**
- **콘텐츠 소재 4:** ①다 해봤는데 왜 무너지나(증상만 쫓음) ②몸 중심→마음 중심(무너짐의 사슬) ③쉬는 게 더 불안한 이유 ④완벽한 몸 vs 살아있는 중심(죽은 균형).
- **3단계 배치:** 발견=공감 훅 / 탐색=Why 서사 / 결정=바이오·후기 신뢰.

## Class 9. 완성 (총정리)
8개 종합 = 전부 **'중심(center)'** 한 점으로 수렴 (일관성 ✓).
- **큰 목표(1년):** 영어 IG·틱톡 10만 → 해외 세미나 → 책 → 외국인 TTC 방한.
- **중간목표:** ①시그니처 포맷 정착(주 3~4개) ②Why·중심 서사 캐러셀 10개 ③무료 리드마그넷(nervous system reset).
- **이번 달:** IG 바이오 교체 / 릴스 3개 / Why 캐러셀 1개.
- **한 문단:** 다 해봤는데도 조용히 무너지는 여자에게 몸의 중심→마음·삶의 중심을 세우는 법을 가르친다. 완벽한 몸이 아니라 '살아있는 중심'을 좇고, 증상이 아니라 원인=중심으로 간다. 나도 세우는 중이라 정직하게 함께 걷는다. 진짜 중심은 하나님 — Soli Deo Gloria. **jihyessence, Rebuild your center.**
