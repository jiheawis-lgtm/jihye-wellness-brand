# 쇼츠 반자동 파이프라인 (jihyessence)

> 목적: 대본→자막→영상→발행을 **매번 같은 순서**로. 지혜님이 안 지치고 계속 찍게.
> 원칙: 완전자동(AI 영상) X — 브랜드(진짜·평온)를 깎음. **반자동**: 글은 자동, 영상은 고정 템플릿.

## 누가 뭘 하나
- ✍️ **대본·온스크린 자막·캡션·해시태그·샷리스트** = **클로드(자동).** 지혜님 목소리로 써서 저장소 `scripts/`에 저장.
- 🎬 **촬영** = 지혜님 (고정 세팅: 창가·낮·세로 9:16·클립 몇 개).
- ✂️ **편집** = 지혜님, **CapCut 고정 템플릿** (웜 프리셋 1 + 자막 스타일 1 + 자동자막 기능).
- 📤 **발행** = 지혜님이 **"올려"** 할 때만. (IG + 틱톡)

## 도구
- **CapCut**(무료 폰 앱) — 자동자막·필터·음악 다 됨.
- **코드·API 키 필요 없음** (지금 단계엔). 나중에 더 자동화할 게 생기면 그때 "이 열쇠 발급해줘"라고 딱 짚어줄게요.

## 반복 절차 (매 영상마다 똑같이)
1. **주제** 정하기 (주제 은행에서 하나)
2. **클로드가 대본팩 생성** → `scripts/`에 저장 (대본·자막·캡션·해시태그·샷리스트)
3. **지혜님 촬영** (샷리스트대로, 창가·낮)
4. **CapCut 템플릿**에 클립 넣고 → 웜 필터 + 자막 + calm 음악
5. **커버 + 해시태그 + 첫 댓글** 붙이기
6. **"올려"** 하면 IG·틱톡 발행

## 고정 스타일 (브랜드 잠금 — 매번 동일)
- 색: 웜 크림 프리셋 + 필름 그레인
- 자막: 가는 크림/화이트 폰트 하나, 아래쪽, 절제
- 음악: calm / ambient / soft piano, 낮은 볼륨
- 편집: 느리게, 급한 컷 X
- 등장: 얼굴은 필름톤으로 조용히 (연출된 밝음 X)
