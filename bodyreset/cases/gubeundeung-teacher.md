# 사례 #5 — 굽은등 선생님 (풀업 시 목통증 → 목·엉덩이 힘으로 등 세우기)

> 날짜: 2026-07-24 · 상태: ✅ 시퀀스 기록 · 출처: 지혜님 수업 관찰.

## 회원 카드
- **굽은등(흉추 과후만)**이 핵심 문제.
- 운다체어 페럴러 아치 풀업 시 **목통증 호소** — 심지어 **직전에 목을 20분 푼 후에도** 통증.

## 소견 분류
- 굽은등 = 🔺흉추 후만·등 약함 / 풀업 시 목통증 = 💥터진 끝(목이 등·팔 일을 대신) / 목 풀어도 안 사라짐 = 원인이 목이 아님(원칙①).

## 수업 시퀀스 (그대로 + 이유)
1. **4발 동물처럼 기어다니기** → 대흉근·광배 강화 + 고관절 절구 원운동 → **결론: 흉추쪽 등힘이 살아남.**
2. **풀업** → 목통증 완화됨.
3. **드롭백** → 엉덩이 힘 빡 + **전거근 힘으로 벽 세게 밀기.**
4. 풀업 → 드롭백 반복.
5. **중둔근 15×3** → 골반을 감싸는 압력↑ → 기립에 수월한 몸.
6. 풀업 → 드롭백.
7. **교근 체크.**
8. 결과: **목 안 아프고, 고꾸라질 두려움 없이 안정적, 저절로 올라감.**

### 원장님 원리
- **풀업 시 척추가 힘있게 길어져줘야** 한다. 못하면 팔힘으로 버팀 → **미는 힘이 불안정하면 두려움**을 느낀다. (축성 신장 = 안정 = 공포 해소)
- 이후 **궁뎅이 파워업(운다체어 테이블탑):** 햄스트링 쥐 → 페달 펌핑 멈추고 **페달 바닥까지 누른 채 엉덩이 들고 버티기 3세트**(등척성) → 페달 펌핑 3세트(핸즈온 = 중부 승모).
- **캐딜락 숄더 롤다운**(등 약하니 등+엉덩이 함께) → **광배를 잘 찾아야 비로소 엉덩이 힘을 쓴다.**
- **캐딜락 푸시뜨루바** → **힐로 아치**(골반 턱킹인 사람은 힐 누르고 아치하면 고관절이 더 열림).
- **원장님 결론: 목의 힘·엉덩이 힘이 생겨야 등 불룩한 게 가라앉는다.**

## 팩트체크 + 근거
- ✅ **4발 기기 = 흉추·전거근 통합 운동:** 기어가기는 견갑 안정·흉추 신전·코어 협응을 동시에 살리는 정평 있는 운동.
- ✅ **광배 ↔ 엉덩이 = 후방 사선 슬링:** 광배근 ↔ 반대측 대둔근이 흉요근막으로 연결. "광배를 찾아야 엉덩이 힘을 쓴다"는 이 슬링의 정확한 표현. [chain-library 후방 사선 슬링](../01-chain-library.md) 근거.
- ✅ **풀업 = 축성 신장이 안정을 만든다:** 척추가 길어지며 견갑이 안정돼야 팔이 편히 미는 힘을 냄. 불안정 → 팔로만 버팀 → 두려움. [원리8 엘리베이터](../02-class-exercises.md)와 동일 축.
- ✅ **목 힘(심부 목굽힘) + 엉덩이 힘(둔근) → 굽은등 완화:** 상부교차(굽은등·거북목) + 하부교차(골반) **동시 교정** 논리와 일치. 목·팔이 대신 버틸 명분이 사라짐.
- ✅ **햄스트링 쥐 → 등척성 버티기 전환:** 경련 시 반복 수축(펌핑) 중단하고 등척성으로 바꾸는 것은 안전한 조치.

## 사슬 한 줄 (가설)
흉추 후만·등 약함 → 풀업/기립을 **목·팔이 대신** 떠맡음 → 목통증 💥. 되감기 = 흉추 등힘 + 광배–둔근 후방 사슬 + 목·엉덩이 힘 → 등이 스스로 서고 목이 해방.

## 정직 플래그
- 목통증이 팔/손 저림·방사통 동반이면 즉시 의뢰(신경 신호).
- 굽은등은 구조적(쇼이어만 등)일 수 있음 → 진행·통증 지속 시 영상 평가 권고.
