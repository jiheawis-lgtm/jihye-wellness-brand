# 사례 #4 — 물렁이 선생님 (급감량·과가동, 오른쪽 요방형근·허리통증)

> 날짜: 2026-07-24 · 상태: ✅ 시퀀스 기록 · 출처: 지혜님 수업 관찰.

## 회원 카드
- 갑자기 살을 많이 빼서 **살·근육 탄력도 저하**, 몸이 금방 무너지지만 **그만큼 운동시키면 빨리 변함**(가소성 큼).
- **오른쪽 요방형근(QL) 불룩**, **오른쪽 견봉 올라감**, **오른쪽 허리통증**을 달고 삶.

## 소견 분류
- 오른쪽 QL 불룩 = 🔺편측 과사용 / 오른쪽 견봉 상승 = 🔺 / 오른쪽 허리통증 = 💥터진 끝 / 전반 탄력저하 = 🔻(과가동·저긴장).

## 수업 시퀀스 (그대로 + 각 단계 이유)
1. **측두근·교근·후두하근 터치** → 신경 스위치(고유수용) 켜기. 〔원리2〕
2. **한다리씩 갈매기 자세** → 심부 전방선(교근↔장요근) 앞면 이완.
3. **고등어 자세(레더배럴 사이드 행)** → 측면·앞면 전체 이완. *극심한 허리통증* → **한 자세로 오래 정체시키지 않고 앞뒤로 움직이며 늘리도록 유도, 오래 안 함.** 아파도 밸런스 위해 진행.
4. **링 대흉근 강화.** 〔대흉근 링운동은 별도 기록 참조〕
5. **캐딜락 이두 강화.** 하이퍼 엘보 있으나 이두 이완강화 큐 진행 — **이유: 몸통에 붙은 문제(견봉 상승)를 하이퍼된 팔꿈치보다 더 크게 봄.**
6. **아령 체스트 오픈.**
7. **엎드려 능형근·회전근개 강화.** 오른쪽 기립근 불룩하지만 **한쪽 더 무겁게/자세 변경 없이 양다리를 하늘로 올리며** 능형근·회전근개를 잡으니 **알아서 밸런스**가 맞춰짐(과가동 바디 특성).
8. **홀스백.**
9. **전완 물구나무 3세트.**

## 팩트체크 + 근거
- ✅ **터치 → 이완 → 강화 순서:** 신경 스위치(후두하) → 심부 전방선(장요근) → 측면 이완(고등어) → 그 다음 강화. 과긴장 이완 후 재강화 = 표준 순서.
- ✅ **"오래 정체 대신 앞뒤 움직이며":** 급성 통증 부위는 정적 압박·장시간 스트레칭보다 **가동 범위 내 동적 움직임**이 안전. 과가동 바디엔 특히.
- ✅ **몸통 가까운 문제 우선(견봉 > 하이퍼엘보):** 근위부(몸통·견갑) 안정이 원위부(팔꿈치)를 지배 = 근위→원위 원칙(regional interdependence)과 일치.
- 🟡 **양다리 들기로 자동 밸런스:** 과가동·저긴장 바디는 좌우 미세조정보다 **전체 후방 사슬 공동활성**이 더 효과적일 수 있음(개인차).

## 사슬 한 줄 (가설)
전반 저긴장(탄력↓) → 오른쪽이 QL·기립근으로 **편측 과사용**해 몸을 지탱 → 오른쪽 허리 💥. 되감기 = 중심(심부 전방선) 이완·재활성 → 후방 사슬 균형 강화 → 편측 과사용이 명분을 잃음.

## 정직 플래그
- 과가동 = **오래 늘리기 금물**, 강화·안정 중심. 통증부는 동적으로 짧게.
- 만성 편측 허리통증 지속·악화·방사통이면 의뢰.
