# 사례 #2 — 대사질환·신장 부종 여성

> 상태: **🕗 내용 업로드 대기** — 지혜님이 몸 특징 + 통증/증상을 올리면 [7단계 절차](../00-thinking-method.md)로 사슬을 분석한다.
> 이 파일은 자리(공간)를 먼저 잡아둔 것.

---

## ⚠️ 먼저 — 이 케이스는 의료가 우선 (정직 플래그)

**대사질환 → 신장 문제 → 부종(붓기)**은 **의학적 상태**다. 바디리셋의 "무너짐의 사슬"은 **움직임 코칭 보조**일 뿐, 신장·대사 관리를 대신하지 않는다.

- 부종(특히 양쪽 다리·전신·얼굴, 갑작스러운, 눌러서 자국 남는 함요부종)은 **신장·심장·순환계 신호**일 수 있음 → **의료 관리가 최우선.**
- 움직임 코칭이 도울 수 있는 범위: 순환 촉진(부드러운 움직임·호흡·발목 펌프), 전신 정렬·중심 회복으로 **삶의 질 보조.** 치료가 아님.
- **레드플래그**(호흡곤란, 급격한 부종 증가, 한쪽만 붓고 아픔=혈전 의심, 소변량 급감 등) → 즉시 의료 의뢰.

→ 그래서 이 케이스는 사슬 분석을 하되, **"의료와 나란히 가는 보조"**라는 프레임을 처음부터 명시한다.

## 회원 카드 (채워질 예정)

```
[회원 카드]
- 기본: 나이/성별, 하루 자세, 운동력
- 대사/신장 상태: 진단명, 현재 의료 관리 여부, 부종 위치·양상
- 습관 패턴:
- 통증: 어디가 / 언제 / 어떤 느낌
- 관찰(있으면): 좌우 비대칭 / 짧음·굳음 / 약함 / 편법 동작 / 관절 가동 / 정렬
- 이미 아는 것: 과거 부상/수술/진단
```

## 7단계 분석 (내용 오면 채움)
1. 터진 끝 표시 —
2. 소견 분류(🔻🔺🧱🌀) —
3. 연결선에 얹기 —
4. 뿌리 도미노 —
5. 사슬 한 줄 —
6. 되감기 순서(stay) —
7. 정직 플래그 & 확인거리 — (의료 우선 프레임 유지)
