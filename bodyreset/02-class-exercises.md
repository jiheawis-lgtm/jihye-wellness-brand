# 수업 운동 설명 모음 (Class Exercises)

> 만든 날: 2026-07-24 · 상태: **살아있는 문서** — 지혜님이 수업에서 한 운동을 올리면 여기에 쌓임.
> 목적: 각 운동이 **"어느 사슬/센터를 되감는지"**를 기록해 → [사고법](00-thinking-method.md)과 [연결지도](01-chain-library.md)의 **학습 재료**로 삼기.
> 즉, 운동을 그냥 나열하는 게 아니라 **"이 운동은 무너짐의 사슬의 어디를 되감나"**로 태그해 사고법과 이어붙인다.

---

## 이 파일을 쓰는 법

운동 하나를 올릴 때 아래 **운동 카드** 틀로 정리한다(있는 것만 채워도 됨). 빈칸은 클로드가 "확인거리"로 되돌려줌.

```
[운동 카드]
- 운동명:
- 동작(무엇을 하나): 자세 / 움직임 / 호흡
- 목표 근육·관절:
- 되감는 사슬/센터: (어느 라인·슬링·운동사슬? 어느 센터를 붙드나 — 01-chain-library 참고)
- stay 요소: (어디를 '붙들며' 하나 = stay에 의한 mobility 포인트)
- 어떤 무너짐 패턴을 되감나: (예: 전거근 약→목 굳음 되감기)
- 흔한 편법/실수: (회원이 어떻게 도망가나)
- 큐잉(코칭 말): (회원에게 주는 한마디)
```

**태그 규칙:** 각 운동에 🔻약함 활성 / 🔺굳음 이완 / 🧱관절 공간 / 🌀편법 교정 중 무엇을 하는지 표시 → 사고법의 소견 분류와 짝을 맞춘다.

---

# 원리 노트 (수업에서 배운 개념)

> 2026-07-24 지혜님이 쏟아낸 오늘 배운 것들. 각 원리에 **팩트체크 + 보조 근거** 첨부.

## 원리 1 — 견갑골 안정화가 견관절을 살린다
**정리:** 견갑골 안정화 → 견관절 기능. **힘 = 삼각근, 미세조절 = 회전근개, 앞으로 들기 = 대흉근, 뒤로 들기 = 광배근.**
**팩트체크 ✅:** 삼각근(대근육 파워) vs 회전근개(상완골두 센터링·미세조절)는 표준 **짝힘(force couple)** 개념. 대흉근 쇄골두 = 어깨 굴곡(앞), 광배 = 어깨 신전(뒤). 견갑이 흔들리면 이 4개가 제 방향을 못 낸다.
**태그:** 🔻전거근·회전근개 활성 / 센터 = 견갑 안정.

## 원리 2 — 턱(교근)과 장요근은 한 줄이다 = 심부 전방선 "신경 스위치"
**정리:** 측두근→교근→후두하근 골지 마사지(신경 스위치 메인키) → 갈매기 자세로 몸 앞 이완 → **어깨가 툭 떨어짐.** 교근 풀면 장요근 풀리고, 장요근 풀리면 교근 이완이 더 오래간다. 골반을 열어 턱 문제를 컨트롤.
**팩트체크:**
- ✅ **후두하근 = 신경 스위치:** 후두하근은 몸에서 **근방추(고유수용 센서) 밀도가 손꼽히게 높은** 근육(그램당 방추 수가 큼). 머리 위치·전신 톤·균형의 고감도 스위치라는 비유, 근거 탄탄.
- ✅ **교근 ↔ 장요근 = 심부 전방선(Deep Front Line):** 턱(교근·측두근)–심부 목–횡격막–장요근–골반저가 **한 근막 라인**. 그래서 "전혀 다른 곳인데 같이 감"이 설명된다. 우리 [chain-library ⭐심부 전방선](01-chain-library.md)과 정확히 일치.
- 🟡 **"이복근은 2조인트 근육이라서":** 이복근(digastric)은 턱–설골 근육. 핵심 다리는 이복근보다 **심부 전방선의 근막 연속성**으로 보는 게 더 정확. (2조인트·방향결 비유는 느낌은 맞음.)
- **근거:** 골지건기관 자극 → 반사 이완(autogenic inhibition) + Myers 아나토미 트레인즈 Deep Front Line.
**태그:** 🔺교근·후두하 이완 / 🔺장요근 이완 / 센터 = 심부 전방선.

## 원리 3 — 쇄골이 대각선 위로 뻗는 이유
**정리:** 대흉근·광배·견갑골 불안정 + 전거근 약 + 이두 약 → 윗승모근이 뒤에서 당김 → 쇄골이 대각선 위로. 밸런스가 맞으면 쇄골이 일자로 내려온다.
**팩트체크 🟡:** 전거근 약 + 윗승모 우세 → 견갑 거상·하방회전 → 쇄골 각도 상승. [카탈로그 #1(전거근 약→목 굳음)](01-chain-library.md)의 자매 소견. (시각 소견은 개인차 커서 확인 필요.)
**태그:** 🔻전거근·이두 / 🔺윗승모 / 🧱쇄골 정렬.

## 원리 4 — 계단 오르면 왜 숨이 찰까 (못 뱉어서 + 장요근–횡격막)
**정리:** 정답 = **숨을 못 뱉어서.** 갈비 주변근을 강화해 완전히 짜내면 들어오는 몸이 된다. 계단 = 고관절 굴곡 → 장요근 활성, 장요근이 흉추12에 붙고 횡격막도 흉추12 근처 → 숨참.
**팩트체크:**
- 🟡 **"못 뱉어서":** 부분적 진실 + 좋은 코칭 프레임. 불완전한 날숨 → 잔기량↑ → 신선한 공기 못 들어옴. 보편 생리로는 단순화지만 코칭 원리로 타당.
- ✅ **장요근–횡격막 연결:** 장요근(T12–L4/5)과 횡격막 각(crura, L1–L3)은 **내측 활꼴인대(medial arcuate ligament)로 근막 연결**. 장요근 긴장 → 횡격막 움직임 제한 → 얕은 호흡. 문헌 근거 있음. "흉추12"는 정확히는 T12–L3 영역(약간 단순화)이나 방향은 맞음.
- ✅ 계단 = 고관절 굴곡 → 장요근 활성 부하 → 횡격막 눌림 = 논리 일치.
**태그:** 🔻갈비 호흡근 / 🔺장요근 / 센터 = 횡격막–골반저.

## 원리 5 — 하품은 들숨일까 날숨일까 🔴 정정 필요
**수업 정리:** "날숨. 뇌 산소 부족 → 이산화탄소 내보내고 산소 마시려고."
**팩트체크 🔴 — 이 항목은 최신 과학과 반대예요:**
- 하품의 정의적 국면은 **크고 깊은 들숨(deep inhalation)** + 짧은 날숨 → 하품은 **주로 "들숨"**.
- "산소부족/이산화탄소" 이론은 **1987년 Provine 연구로 이미 반증**. 산소·CO₂ 농도를 바꿔도 하품 빈도는 안 변하고, 하품은 혈중 산소·CO₂를 유의미하게 바꾸지 않는다.
- 현재 유력 가설 = **뇌 냉각(thermoregulation).** 깊은 들숨이 두부 혈류·뇌척수액 압력을 바꿔 뇌 온도를 식힘.
- **정직 메모:** 운동 처방엔 영향 없지만, **브랜드 밖 콘텐츠로 낼 땐 꼭 고쳐야** 함(사실 오류). 근거는 문서 하단 출처.
**태그:** (원리 아님 · 사실 정정 항목)

## 원리 6 — 홀스백 티칭 2가지 (몸 유형별 큐잉)
**정리:** **후만형(뻣뻣)** → 냅다 내전을 쪼으라. **물렁 + X자 다리 + 전만** → 내전을 조이되 **중둔근을 함께** 느끼게 유도.
**팩트체크 ✅:** 과가동·외반슬(X다리)은 순수 내전만 강조하면 무릎 안쪽 붕괴가 악화될 수 있어 **중둔근(외전근) 공동활성**으로 전두면 균형을 잡는 게 맞다. 뻣뻣·후만은 내전 구심 자체가 부족해 단순 큐가 유효. 유형 판별이 핵심.
**태그:** 🌀편법 교정(유형별 큐잉).

## 원리 7 — 내전 우세 → 둔근 외전 힘이 생긴다
**정리:** 내전의 힘을 더 우세하게 만들면 둔근 외전의 힘이 생긴다.
**팩트체크 🟡:** 내전근–외전근은 전두면에서 골반을 잡는 **짝**. 내전근(특히 대내전근)이 안정된 기반을 주면 중둔근이 제대로 작동할 여지가 생김(골반 센터링·co-activation 개념). 단순 인과라기보단 짝힘/centration 모델.
**태그:** 🔻중둔근 / 센터 = 골반 전두면.

## 원리 8 — 엘리베이터 원리 (무겁게 내리면 반대가 올라간다) = 축성 신장
**정리:** 꼬리뼈를 잘 묶어 내려야 척추가 반대로 뻗고, 광배를 잘 끌어내려야 전거근을 충분히 대각선으로 전인할 수 있다. 추가 내려가며 엘리베이터가 올라가듯.
**팩트체크 ✅:** 필라테스·짐로토닉 핵심 **"대립을 통한 길이(axial elongation)".** 하방 앵커(꼬리뼈·광배 하강)가 상방 신장(척추·정수리)을 만든다. 광배 하강 → 견갑 안정 → 전거근 전인 여지.
**태그:** 센터 = 축성 신장 / 🔻전거근 전인.

|---|---|---|---|
| **전완 물구나무(나무/전갈자세)** | 전완 바닥, 거꾸로 서서 어깨 힘 밸런스 체크 | 견갑 안정 진단(휘청임=불안정) | 🌀진단 |

| **이두 eccentric(3kg, 천천히 내리기)** | 어깨로 당겼다 무게로 천천히 이두를 늘리며 내림 ×10×3 | 삼각근 후면·후방 사슬 활성, 후두하 부하 감소 | 🔺이두 이완강화 |
| **고등어(레더배럴 사이드 행)** | 손끝~발 측면·배 앞면 전체 이완 | 측면라인·심부 전방선 이완 → 고관절 열림 | 🔺측·전면 이완 |
| **스콜피온(레더배럴)** | 엉덩이 힘으로 고관절 앞쪽 열기 | 장요근·고관절 앞 이완, 둔근 활성 | 🔺고관절 앞 / 🔻둔근 |
| **홀스백** | 내전 힘 + 팔 전인(엘리베이터 원리) | 내전·전거근 전인, 어깨 놓기 체크 | 🔻내전·전거근 |
| **갈매기(한다리씩)** | 누워 몸 앞 이완 | 심부 전방선(교근↔장요근) 이완 | 🔺전면 이완 |
| **링 대흉근 강화** | 링으로 가슴 조임 | 대흉근·흉곽 정렬 → 호흡 | 🔻대흉근 |
| **캐딜락 이두 이완강화** | 이두 큐(하이퍼엘보 있어도 몸통 가까운 견봉 문제 우선) | 견관절 센터링 | 🔺이두 |
| **아령 체스트 오픈** | 가슴 열기 | 대흉근·라운드숄더 되감기 | 🔺가슴 이완 |

| **풀업(운다체어)** | 아치+페럴러 매달려 당김 | 척추 축성 신장 + 견갑 안정 | 🔻광배·축성 |
| **드롭백** | 엉덩이 힘 + 전거근으로 벽 밀기, 후굴 | 둔근·전거근 협응 | 🔻둔근·전거근 |
| **중둔근 15×3** | 측면 골반 안정 | 골반 압력↑ → 기립 수월 | 🔻중둔근 |
| **운다체어 테이블탑 / 페달 펌핑** | 페달 바닥 누르고 엉덩이 들고 버티기 → 펌핑 | 둔근·햄스트링(쥐나면 등척성으로 전환) | 🔻둔근 |
| **캐딜락 숄더 롤다운** | 등+엉덩이 함께 강화 | 등–둔근 후방 사슬 | 🔻등·둔근 |
| **힐로 아치** | 힐 누르고 아치(골반 턱킹인 사람) | 힐 압력 → 고관절 더 열림 | 🧱고관절 |
