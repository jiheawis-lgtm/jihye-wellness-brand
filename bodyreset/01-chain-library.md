> **이 파일의 스파인 = 지혜님이 가르치고 관찰한 사슬(◈ 원본).** 제 일반 해부학은 **📚 보조(운율, 증명 아님)**로 아래에 붙는다.

## 📖 용어 사전 (쉬운 말)
| 해부 용어 | 쉬운 말 | 하는 일 |
|---|---|---|
| 이상근 (piriformis) | 엉덩이 깊은 곳 작은 근육 | 다리를 **바깥으로 돌림(외회전)** |
| 전거근 (serratus anterior) | 옆구리~날개뼈 근육 | 날개뼈를 갈비뼈에 **딱 붙여 잡음** |
| 후두하근 (suboccipital) | 뒤통수 밑 작은 근육 | 머리 미세조절 · **신경 스위치**(근방추 최다) |
| 교근·측두근 (masseter/temporalis) | 턱 씹는 근육 | 저작 · 교감신경과 연동 |
| 장요근 (iliopsoas) | 고관절 앞 깊은 근육 | 고관절 굽힘 · 척추-골반 안정 |
| 대둔근·중둔근 (glute max/med) | 엉덩이 뒤·옆 | 고관절 신전 / 골반 옆 안정 |
| 내전근 (adductors) | 허벅지 안쪽 | 다리를 **안으로 모음** · 골반 안정 |
| 대흉근 (pec major) | 가슴 근육 | 어깨 앞으로 · 흉곽 |
| 광배근 (latissimus) | 넓은 등 근육 | 어깨 뒤로 · 등-골반 잇기 |

# PART 1 — ◈ 바디리셋 원본 사슬 (스파인)

> 지혜님이 실제로 가르치고/관찰한 사슬. 새 케이스는 **먼저 여기서** 꺼내 쓴다.

### C1. 내전근 → 대둔근 → 골반 (전방경사 사슬) ◈
`내전근 약화 → 복식 휴면 → 대둔근 억제 → 이동수축 → 전방경사`
- 내전근은 **골반 안정의 핵심.** 대둔근에 힘이 있으면 복부 부하가 떨어진다.
- **센터:** 골반 중립(구심). **출처:** 대둔근·내전근·골반 카드(day0/1).
- 📚 울림: 내전근–골반저–복부는 심부 전방선 캐니스터로 연결.

### C2. 견봉 상승 사슬 ◈
`내전·중둔근 약화 → 아랫배 경직·복직근 지지 상실 → 대흉근 힘 못 씀 → 순수 팔힘 → 이두 과수축 → 견봉 상승` (+ 대흉근이 못 받쳐 후두하근 재경직 = 마사지 도루묵)
- **되감기:** 이두 통증·엘보 호소 시 → 대흉근 먼저 죽이고 → 원인(내전·중둔근) 강화.
- **센터:** 몸통 → 어깨. **출처:** 대흉근 카드(day0/1). *정직: 기능적 모델(개인차 큼).*
- 📚 울림: 대전제 분포①(중심 붕괴→약한 끝) + 루프③.

### C3. 교감신경 스위치 ◈
`측두근(대문) → 교근(안방문) → 후두하근(골지)` — 눌러 흔들어 교감을 끈다. 운동 전 세팅 + 텐션 체크.
- **센터:** 신경계(호흡·이완). **출처:** 측두근·교근 카드(day0/1).
- 📚 울림: 후두하근 = 근방추 밀도 최다 → 전신 톤의 고감도 스위치(근거 있음).

### C4. 턱 ↔ 장요근 상호 이완 ◈✎
`교근 풀면 장요근 풀림 · 장요근 풀면 교근 이완이 더 오래감 → 어깨 툭 떨어짐`
- **센터:** 심부 전방선. **출처:** 오늘 수업(지혜님 설명) + 갈매기 동작.
- 📚 울림: 심부 전방선(턱–횡격막–장요근–골반저) 근막 연속.

### C5. 오른쪽 나선 (지혜님 몸) ◈
`발목/아킬레스(틈 없음) → 이상근(고관절 외회전·씹힘) → 전거근 약 → 목 나무토막(터진 끝)`
- 전부 한쪽 = **나선 패턴.** 뿌리 = 발목+고관절이 나선의 위·아래를 맞물어 잠금.
- **출처:** 오늘 선생님 관찰([사례 #1](cases/2026-07-24-jihye-right-spiral.md)).
- 📚 울림: 스파이럴 라인(몸을 나선으로 감는 줄).

### C6. 전거근 약 → 목이 대신 → 목 굳음 ◈
`전거근 약(날개뼈 못 잡음) → 어깨올림근·윗승모가 대신 → 목 나무토막` + **"대흉근 약자는 뒷골이 무조건 굳는다."**
- **센터:** 어깨 → 목. **출처:** 오늘 + 대흉근 카드.

### C7. 견갑 안정 먼저, 그다음 이두 ◈
`이두 강화 시 뒷골(후두하) 굳으면 → 회전근개·능형근부터 강화` (견갑이 서야 팔 부하가 목으로 안 샘)
- **센터:** 견갑 안정. **출처:** 오늘 실전 + 대흉근 카드.

### C8. 광배 찾아야 엉덩이 힘 쓴다 ◈
`광배근을 잘 끌어내려야 → 비로소 둔근이 작동`
- **센터:** 등–골반 후방 사슬. **출처:** 굽은등 선생님 케이스(원장님).
- 📚 울림: 후방 사선 슬링(광배 ↔ 반대측 대둔근, 흉요근막).

### C9. 내전 우세 → 둔근 외전 힘 ◈
`내전의 힘을 더 우세하게 만들면 → 둔근 외전의 힘이 생긴다`
- **센터:** 골반 전두면. **출처:** 오늘 수업. *정직: 짝힘/centration 모델.*
- 📚 울림: 내전근–외전근 전두면 짝힘.

### C10. 계단 숨참 ◈
`계단 = 고관절 굴곡 → 장요근 활성 → 횡격막(흉추12 공유) 눌림 → 숨참` · 정답은 "**못 뱉어서**".
- **센터:** 호흡–중심. **출처:** 오늘 수업.
- 📚 울림: 장요근–횡격막 내측 활꼴인대 연결 + CO₂/비움([세계관 4번](00-worldview.md)).

### C11. 목 힘 + 엉덩이 힘 → 등 불룩 가라앉음 ◈
`목의 힘·엉덩이 힘이 생겨야 → 굽은등(등 불룩)이 가라앉는다`
- **센터:** 상·하 동시. **출처:** 굽은등 선생님(원장님).
- 📚 울림: Janda 상부교차 + 하부교차 동시 교정.

### ⚙️ 마스터 렌즈 — 장력과 압박 ◈
몸을 세우는 힘은 둘뿐: **장력**(복직근+장요근 / 복직근+내전근 / 햄스트링+대퇴직근) · **압박**(사각근 / 전거근 / 둔근). 모든 사슬은 결국 **어디서 장력·압박이 무너졌나**로 읽는다. 상세 → [02 '장력과 압박'](02-class-exercises.md). 📚 울림: 텐세그리티.

### C12. 힘의 전달 방향 (말단→뇌) ◈
`엄지 → 종골 → 좌골 → 치골 → 흉추12 → 극돌기 → 뇌`
- **센터:** 말단(발)에서 중심축까지. **출처:** 이번 수업 〔#4〕. 흉추12 = 장요근·횡격막 교차(C10).

### C13. 인코어·아웃코어 + 복직근의 첫 문 ◈
`장요근 = 인코어 · 복직근 = 아웃코어` / `복직근에 압력 채우는 첫 문 = 내전근`
- **센터:** 코어 압력. **출처:** 이번 수업 〔#12·#13〕. (C1·원리9와 한 줄.)

### C14. 장요근 열면 교근 열림 (아래→위) ◈
`장요근을 열어주면 → 교근이 열린다`
- = **C4의 역방향.** 턱↔장요근은 **양방향.** **센터:** 심부 전방선. **출처:** 이번 수업 〔#11〕.

### C15. X/O다리 → 고관절 어긋남 → 치골 ◈✎
`이상근 과수축 + 내전근 과이완 + 장요근 수축불량 → 고관절 빠짐 → (여)치골 튀어나옴` / 고관절 어긋나면 **하복부 힘이 엄지발가락으로 전달 안 됨.**
- **되감기:** 내전 강화 + 단축 이상근 정상화 → 치골이 툭 떨어짐(헌드레드 공 끼우기). 안 되면 턱·후두하 스위치 ON.
- **센터:** 고관절 정렬. **출처:** 이번 수업 〔#2〕. *정직: 치골 패턴 ✎.*

### C16. 발가락 반사 → 상위 관절 (KSNS) ◈
`1번 발가락(전경골근) 약 → 무릎·요추5 통증` / `4·5번 발가락 약 → 고관절 문제` / 하복부 힘 ↔ 발가락 힘.
- **센터:** 말단 반사→정렬. **출처:** 이번 수업 KSNS 〔#1〕.

# PART 2 — 📚 일반 해부학 참고 (운율, 증명 아님)

> **여긴 클로드가 얹은 재료.** PART 1의 원본 사슬이 "왜 그렇게 이어지나"를 해부학으로 **울려줄 뿐**, 원본을 대체하지 않는다.

- **⭐ 심부 전방선 (Deep Front Line):** 발 안쪽→종아리심부→내전근→골반저→횡격막→목 앞→턱. = **중심(구심)의 해부학적 집.** → C1·C3·C4·C10과 울림.
- **🌀 나선 라인 (Spiral Line):** 몸을 나선으로 감아 좌우·회전을 만듦. 한쪽 짧아지면 전신이 그쪽으로 감김. → C5와 울림.
- **후방 사선 슬링:** 광배 ↔ 반대측 대둔근(흉요근막). → C8·C11.
- **전방 사선 슬링:** 내전근 ↔ 반대측 복사근 ↔ 전거근. → C2(내전–전거근).
- **위아래 운동사슬:** 발목 배측굴곡 제한→무릎→고관절 외회전 보상 / 흉추 뻣뻣→어깨·목 보상. → C5·C6.
- **후두하 근방추 / 장요근–횡격막 내측활꼴인대 / 보어효과(CO₂):** → C3·C10, [세계관](00-worldview.md).

## 🧭 이 지도 쓰는 법
1. 회원 소견을 [사고법 STEP 2](00-thinking-method.md)로 태그(🔻🔺🧱🌀).
2. **먼저 PART 1(◈ 원본 사슬)**에서 맞는 사슬을 찾는다.
3. 없으면 PART 2(📚 해부학)로 "왜 이어지나"를 보조 설명.
4. 새로 배운 ◈원본은 **PART 1에 사슬로 승격**(스파인을 계속 키운다).
