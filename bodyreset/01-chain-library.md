# 바디리셋 연결 지도 (Chain Library)

> 만든 날: 2026-07-24 · 상태: **살아있는 문서 (v1)** — 케이스가 쌓이면 계속 굵어짐.
> 목적: [사고법 절차](00-thinking-method.md)의 STEP 3~4에서 **"흩어진 소견을 한 줄로 꿰는" 재료.**
> 이 지도들은 **정밀 배선도가 아니라 유용한 지도**다 — 몸을 읽는 렌즈로 쓰되, 회원의 실제 반응이 지도보다 우선.

---

## 📖 용어 사전 (쉬운 말)

| 해부 용어 | 쉬운 말 | 하는 일 |
|---|---|---|
| 이상근 (piriformis) | 엉덩이 깊은 곳 작은 근육 | 다리를 **바깥으로 돌림(외회전)** |
| 전거근 (serratus anterior) | 옆구리~날개뼈 근육(권투선수 근육) | 날개뼈를 갈비뼈에 **딱 붙여 잡음** |
| 어깨올림근·윗승모 (levator/upper trap) | 목~어깨 위 근육 | 날개뼈를 위로. 약한 전거근을 **대신 떠맡음** |
| 중둔근 (glute med) | 엉덩이 옆 | 걸을 때 골반이 안 떨어지게 잡음 |
| 내전근 (adductors) | 허벅지 안쪽 | 다리를 **안으로 모음(내전)** |
| 심부 목굽힘근 (deep neck flexors) | 목 앞 깊은 근육 | 머리를 **중심에** 붙듦 |
| 배측굴곡 (dorsiflexion) | 발목을 정강이 쪽으로 | 쭈그릴 때·걸을 때 정강이가 앞으로 |
| 외회전/내회전 (ER/IR) | 밖으로 돌림 / 안으로 돌림 | 고관절·어깨의 회전 방향 |

## 🧵 몸을 꿰는 라인/슬링 (같은 소견을 한 줄로 잇는 렌즈)

> "슬링(sling)"과 "라인(line)"은 근육들이 근막으로 이어져 **한 팀처럼 힘을 전달하는 줄.**
> 한 링크가 무너지면 **같은 줄의 먼 곳까지** 부하가 이동한다 → 이게 바디리셋의 "무너짐의 사슬"의 해부학적 몸통.

### ⭐ 심부 전방선 (Deep Front Line) = **"중심(구심)"의 해부학적 집**
`발 안쪽 아치 → 종아리 심부 → 내전근 → 골반저 → 횡격막 → 심부 코어 → 목 앞 심부굴근 → 턱/혀`
- 몸의 **진짜 중심축.** 바디리셋의 **센터/구심과 가장 가까운 라인.**
- 여기가 약하면(구심 상실) **겉근육이 대신 버틴다** → 원칙② "굳음=약함의 그림자"의 근원.
- 되감기의 최종 목적지: 결국 이 선이 다시 붙들 수 있게(stay) 만드는 것.

### 🌀 나선 라인 (Spiral Line) = **한쪽으로 감기는 무너짐**
`머리·목 → 어깨/날개뼈 → 갈비·배 → 골반 → 무릎 → 발 안쪽 아치 → 뒤로 올라와 척추`
- 몸을 **나선으로 감싸** 좌우 균형·회전을 만든다.
- 한쪽이 짧아지면 **전신이 그쪽으로 비틀려 감긴다** = "오른쪽 나선" 같은 **한쪽 쏠림 패턴**의 지도.
- 발아치–고관절–갈비–어깨–목이 **한 나선 줄**로 움직인다 → 멀리 떨어진 소견(발목↔목)이 사실 한 줄일 수 있음.

### 전방 사선 슬링 (Anterior Oblique Sling)
`한쪽 내전근 ↔ 반대쪽 배경사근 ↔ 전거근`
- 걷기·회전에서 몸통 앞면을 잠근다.
- **내전근(고관절) ↔ 전거근(어깨)**를 잇는 줄 → 고관절 내전 문제와 전거근 약화가 **한 슬링**일 수 있음.
- 주의: 보통 **좌우 교차(대각)** 연결. 같은쪽-같은쪽 소견이면 **나선 라인**이 더 잘 맞을 수 있음(둘 다 후보로).

### 후방 사선 슬링 (Posterior Oblique Sling)
`한쪽 광배근 ↔ 반대쪽 엉덩이(대둔근)` (등허리 근막으로 연결)
- 걸을 때 뒷면 추진·천장관절 안정. 요통·엉덩이 약화 케이스에서 자주 등장.

### 심부 종적 슬링 (Deep Longitudinal Sling)
`척추세움근 ↔ 천결절인대 ↔ 뒤허벅지 ↔ 종아리 바깥`
- **발/발목 ↔ 척추**를 잇는 세로줄 → 아래(발목)의 문제가 위(허리)로 올라가는 통로.

### 외측 슬링 (Lateral Sling)
`중둔근 + 허벅지 안쪽 + 허리네모근(QL)`
- 한 다리로 설 때 골반을 수평으로 잡음. 무너지면 걸을 때 골반이 떨어지고 무릎이 안으로.

## ↕️ 위아래 운동사슬 (Regional Interdependence)

한 관절이 굳으면 **이웃 관절이 대신 움직여** 보상한다. (물리치료의 "부위 간 상호의존성" — 확립된 개념)

**아래사슬 (발 → 위로):**
`발/발목 배측굴곡 제한(아킬레스·종아리 굳음) → 무릎이 정강이를 앞으로 못 보냄 → 고관절이 외회전·굴곡으로 편법 → 골반/허리 보상`

**위사슬 (등 → 어깨/목):**
`흉추(등) 뻣뻣 → 날개뼈·어깨가 못 움직임 → 목·팔이 대신 보상 → 목 굳음`

**좌우:** 한쪽이 약하면 → 같은쪽이 "대신 버티며 굳거나" / 반대쪽이 "과사용".

## 🔁 흔한 보상 패턴 카탈로그 (바로 꺼내 쓰는 사슬 조각)

> 소견을 보면 이 카탈로그와 대조 → 익숙한 사슬 조각을 빠르게 인식.

1. **전거근 약 → 목 굳음.** 날개뼈를 못 잡으니 어깨올림근·윗승모가 대신 → 목이 나무토막 + 날개뼈 뜸(winging). 〔사례#1〕
2. **이상근·심부외회전근 짧음/우세 → 고관절 외회전 고정.** 내전·내회전이 안 됨 → **내전을 외회전으로 편법.** 고관절 "씹힘(임핀지먼트)" 느낌. 〔사례#1〕
3. **발목 배측굴곡 제한(아킬레스 굳음) → 위로 보상.** 쭈그리기·보행에서 발 벌어짐·무릎 안으로·고관절 외회전. 〔사례#1〕
4. **상부교차증후군 (Janda):** 〔짧음〕앞가슴·윗승모·어깨올림근 + 〔약함〕심부목굽힘근·아래승모·전거근 → 거북목·굽은등.
5. **하부교차증후군 (Janda):** 〔짧음〕고관절굽힘근·허리세움근 + 〔약함〕엉덩이·복근 → 골반 앞기울임·허리 압박.
6. **중둔근 약 → 골반 떨어짐(트렌델렌버그)** → 걸을 때 무릎 안으로·허리/무릎 통증.
7. **거북목(head forward):** 심부 목굽힘근 약 → 목 뒤·윗승모가 머리를 대신 붙듦 → 목·어깨 굳음, 두통.
8. **교근·후두하 ↔ 장요근 (심부 전방선):** 턱·뒤통수 이완 → 장요근 풀림 → 어깨 툭 떨어짐. 후두하근 = 근방추 최다 = **신경 스위치.** 〔지혜·물렁이 사례〕 ✅
9. **광배 ↔ 반대측 둔근 (후방 사선 슬링):** "광배를 찾아야 엉덩이 힘을 쓴다." 굽은등·요통·풀업·드롭백. 〔굽은등 사례〕 ✅
10. **장요근 ↔ 횡격막 (내측 활꼴인대):** 고관절 굴곡·장요근 긴장 → 호흡 제한 → 계단 오를 때 숨참. ✅
11. **내전근 ↔ 중둔근 (전두면 짝힘):** 내전 우세 → 외전(중둔근) 기능. 홀스백 유형별 큐잉(후만형 vs 과가동·X다리). 🟡
12. **견갑 불안정 → 이두·팔 부하가 목으로:** 견갑(전거근·능형근·회전근개) 안정 없이 이두 강화 시 뒷골(후두하) 굳음 → **회전근개부터 강화.** 〔지혜 사례〕 ✅

*(이 목록은 계속 자란다. 새 케이스에서 반복되는 조각이 나오면 여기에 추가. ✅탄탄 🟡기능적모델)*

## 🧭 이 지도 쓰는 법 (요약)

1. 회원 소견을 [사고법 STEP 2](00-thinking-method.md)로 태그(🔻🔺🧱🌀).
2. 위 **라인/슬링**과 **위아래 사슬** 중 소견들을 **한 줄로 꿰는** 것을 찾는다.
3. **카탈로그**와 대조해 익숙한 조각을 인식.
4. **중심에 가장 가깝고 다운스트림을 가장 많이 설명하는** 링크 = 뿌리 도미노.
5. 심부 전방선(중심)에서 얼마나 멀어졌나로 "구심 상실 정도"를 가늠.
